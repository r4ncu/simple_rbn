# Simple RBN Monitor

Простой монитор спотов из [Reverse Beacon Network](http://reversebeacon.net/) для коротковолновиков.

## Что это

RBN (Reverse Beacon Network) — сеть автоматических приёмников, которые слушают эфир и публикуют "споты" — сообщения о том, какой позывной слышали, на какой частоте, с какой мощностью сигнала (SNR). Это позволяет быстро узнать, куда тебя слышат, не дожидаясь ответа.

Simple RBN Monitor — это обёртка над RBN API, которая показывает все споты на конкретный позывной за последний час в виде простой таблицы.

## Как пользоваться

1. Ввести позывной в поле ввода (например `R4NCU`)
2. Нажать «Поиск» или Enter
3. Таблица заполнится автоматически и будет обновляться каждые 5 секунд

## Что показывает таблица

| Колонка | Описание |
|---------|----------|
| Spotter | Позывной станции, которая услышала сигнал (+ флаг страны) |
| QRB, km | Расстояние до споттера (вычисляется по координатам через формулу Хаверсина) |
| SNR, дБ | Мощность принятого сигнала. Цветовая индикация: зелёный ≥20, жёлтый ≥10, оранжевый ≥0, красный <0 |
| time | Время спота (UTC) |
| freq | Частота в кГц |

Колонки QRB, SNR и time кликабельны — можно сортировать по любой из них.

## Как устроено

### Файлы

- `server.py` — Python-сервер (126 строк)
- `spotted.html` — весь фронтенд в одном HTML-файле (374 строки)
- `render.yaml` — конфигурация деплоя на Render

### Сервер (server.py)

Минимальный HTTP-сервер на стандартной библиотеке Python. Без фреймворков, без зависимостей.

**Что делает:**
- Раздаёт `spotted.html` как статический файл
- Проксирует запросы к RBN API: `/api/spots` → `reversebeacon.net/spots.php`
- Поддерживает persistent-соединение с RBN (переиспользует HTTPS-коннект вместо создания нового на каждый запрос)
- 3-секундный кэш ответов, чтобы не долбить RBN при частых обновлениях
- Keep-alive поток закрывает простаивающие соединения старше 60 секунд
- Dual-stack (IPv4 + IPv6) слушает на `::`

**Почему прокси?** RBN API не поддерживает CORS — браузер не может обращаться к нему напрямую. Сервер выступает посредником.

### Фронтенд (spotted.html)

Один HTML-файл. Никаких фреймворков, бандлеров, зависимостей. Всё внутри:

- **CSS** — тёмная тема, мобильная адаптивность, цветовая индикация SNR
- **JavaScript** — polling каждые 5 сек, вычисление расстояний (Haversine formula), сортировка, маппинг позывных на国旗 через `PREFIX_TO_ISO`

**Логика работы:**
1. Пользователь вводит позывной → `startSearch()`
2. Каждые 5 секунд `fetchSpots()` запрашивает `/api/spots?cdx=POZIVN` 
3. RBN возвращает JSON со спотами и информацией о станциях (координаты, страна)
4. `renderSpots()` вычисляет расстояния, сортирует, рисует таблицу
5. Новые споты добавляются к старым (инкрементально, по `lastId`)

**Флаги стран:** префикс позывной → ISO-код страны → флаг с `flagcdn.com`. Маппинг покрывает ~80 стран.

## Деплой

Один файл `render.yaml`:
```
web: python server.py
```

Render подхватывает, ставит Python, запускает. Без сборки.

## Почему минимализм

- 0 зависимостей (только stdlib Python)
- 2 файла: сервер + клиент
- Нет сборки, нет компиляции, нет конфигов
- Весь фронтенд в одном HTML — можно открыть локально и оно работает (через прокси)
- Весь бэкенд — 126 строк Python
- Работает на бесплатном тарифе Render
