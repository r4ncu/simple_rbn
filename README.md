# Simple RBN Monitor

**Simple RBN Monitor** — минималистичный веб-монитор для Reverse Beacon Network (RBN)

https://simple-rbn.onrender.com

---

## Что это за проект

RBN (Reverse Beacon Network) — это сеть автоматических приёмников по всему миру, которые слушают эфир и публикуют **«споты»** — сообщения о том, какой позывной услышан, на какой частоте и с какой мощностью сигнала (SNR).

Simple RBN Monitor — это легковесный прокси-клиент к RBN API, который показывает споты по одному позывному на интерактивной карте и в таблице.

## Возможности

- **Поиск по позывному** — введите позывной (например, `R4NCU`) и увидите все споты за последний час.
- **Автообновление каждые 5 секунд** — таблица и карта обновляются в реальном времени.
- **Интерактивная карта (Leaflet)** — тёмная/светлая тема, позывной цели отмечен жёлтой точкой, споттеры — цветными маркерами по диапазонам (160M, 80M, 40M…), линии от цели к каждому споттеру, popup-окна с деталями.
- **Таблица спотов** — колонки: Spotter (+флаг страны), расстояние (км), SNR (дБ), время (UTC), частота (кГц). Цветовая индикация SNR (зелёный/жёлтый/оранжевый). Сортировка кликом по заголовкам. Подсветка новых спотов.
- **Флаги стран** — определяются по префиксу позывного через встроенный словарь (~80+ стран).
- **Тёмная/светлая тема** — переключатель, сохраняется в localStorage.
- **Адаптивный дизайн** — работает на десктопе и мобильных устройствах.
- **Автосохранение позывного** — последний запрос сохраняется в localStorage.

## Сильные стороны

1. **Минимализм** — всего 2 файла кода (server.py + spotted.html), ~740 строк, ноль внешних зависимостей (только стандартная библиотека Python на бэкенде, никаких npm, никаких фреймворков).
2. **Простота** — делает одну вещь и делает её хорошо: показать, кто слышит твой позывной прямо сейчас.
3. **Скорость** — встроенное кэширование (3 сек), переиспользование HTTP-соединений (PersistentRBN), автообновление 5 сек.
4. **Самодостаточность** — фронтенд в одном HTML-файле (CSS + JS + HTML внутри), всё включено.

---

Simple RBN Monitor **не заменяет** reversebeacon.net, а решает одну конкретную задачу быстрее, проще и удобнее: ввёл позывной → увидел результаты.

## Размещение на Render.com (free tier)

Приложение запущено на **Render.com** — бесплатный хостинг (Render Web Service).

### Особенности бесплатного тарифа

- **Сервер «засыпает»** после ~15 минут бездействия.
- **При первом обращении** после сна требуется **30–60 секунд на «пробуждение»** (сервер загружается с нуля).
- После пробуждения всё работает штатно, автообновление 5 сек.
- **Нет pinger/uptimerobot** — пользователи просто принимают задержку при первом входе.
- Если приложение не отвечает — подождите 30–60 секунд и обновите страницу.
